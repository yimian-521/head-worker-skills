# head-worker-skills v3.5.2

> 免免蒸馏：八步审码+四原则架构。mianmian-review元Skill。

## 这是什么

一个元 Skill 集合。任何 AI 拿到它，就能陪人类走完一整套沙盒包创建流程——从「我到底想做什么」到「代码写完、验证通过、可以发布」。附带八步审码引擎（mianmian-review）——符号解析→前提检查→数据流→控制流+值域→身份检查→传染性→系统沉默→硬限制分析。

它不是代码生成器。它是**决策框架**：让人在写第一行代码之前，先确认自己走在对的路上。

## 什么才算「错误」

**语法错误不是错误。走错方向才是。**

- 不知道自己要什么，就开始写代码 → **错误**。Skill 会在 Shape 阶段拦住你，先问「你真正想要什么体验」。
- 明明在同一个框架里深耕就能解决，却为了「换个形态」重构整个项目 → **错误**。Skill 的淘汰链不会让你跳过这一问：「不换形态，深耕能达到吗？」
- 做完了一个沙盒包，但别人拿起来不知道怎么用 → **错误**。Skill 会追问「别人能看懂你的初衷吗」，并让你选择兼容层级。
- 性能「刚刚好够」就停手，或者「过度优化」到不可维护 → **错误**。Skill 按类型给出了精确的性能准则——不是越多越好，是刚刚好。
- 报错了不知道问题出在哪一层 → **错误**。Skill 的 `retry_trace` 故障追踪链会把每一层的错误码推回来。
- 审代码靠猜不靠系统 → **错误**。mianmian-review 八步法逐条问到底，三秒定位，17/17全命中。

**一句话：错误不是代码跑不通。错误是你做完了才发现——这个东西从一开始就不该这样做。**
